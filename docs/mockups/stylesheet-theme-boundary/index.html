Stylesheet theme boundary

Static reference for comparing the packaged TreeView state selectors on light, dark, and high-contrast-like host themes. The page keeps runtime stylesheet behavior, public hook promotion, and CSS custom property policy out of scope.

TreeView-owned cueRows use the packaged current, selected, collapsed, loading, error, and drop-target selectors.
Host-owned themeTypography, palette, density, brand tone, and final contrast policy stay with the host app.

Review boundaries

Out of scope

No dark-mode implementation, CSS custom property API, public hook promotion, screenshot baseline, route, CRUD, or authorization policy is introduced here.
